# 🗳️ Urna Digital — Spring Boot

Aplicação desenvolvida com **Spring Boot** para simular uma urna digital, com foco em organização de camadas, boas práticas e facilidade de execução.

---

## 📌 Visão Geral

Este projeto tem como objetivo demonstrar:
- Criação de APIs REST com Spring Boot
- Organização em camadas (Controller, Service, Repository, Domain)
- Execução local simples via Maven
- Estrutura base pronta para evolução

---

## 🛠️ Tecnologias Utilizadas

- Java 17+
- Spring Boot
- Maven
- Spring Web
- Spring Data JPA
- Banco de Dados (MySQL)
- Git

---
